# ============================================================
# AI-Powered Prescription Discrepancy Detection System
# Backend Requirements — Python 3.11+
#
# macOS / MacBook compatibility notes
# ------------------------------------
# This stack runs on macOS (Intel and Apple Silicon M1/M2/M3) with
# the following caveats:
#
#  1. poppler (for pdf2image fallback):
#       brew install poppler
#     PyMuPDF is the PRIMARY PDF→image converter and needs NO system deps —
#     so poppler is only required if you explicitly use pdf2image.
#
#  2. Redis (broker + result backend):
#       brew install redis && brew services start redis
#     Or: docker run -p 6379:6379 redis:alpine
#
#  3. PostgreSQL:
#       brew install postgresql@16 && brew services start postgresql@16
#     Or use any hosted Postgres (Supabase, Railway, Render, etc.)
#
#  4. Apple Silicon (M1/M2/M3) — all packages below ship universal2 or
#     arm64 wheels on PyPI. If pip falls back to building from source:
#       brew install openblas   # for numpy / scikit-learn
#
#  5. faiss-cpu — arm64 wheel available since faiss-cpu 1.7.4+.
#     If install fails: pip install faiss-cpu --no-binary faiss-cpu
#
#  6. xgboost — universal2 wheel available. Falls back to source build
#     on very old pip; upgrade pip first: pip install -U pip
#
#  7. psycopg2-binary — binary wheels for macOS (no libpq install needed).
#
# All other packages are pure-Python or have macOS wheels on PyPI.
# ============================================================
