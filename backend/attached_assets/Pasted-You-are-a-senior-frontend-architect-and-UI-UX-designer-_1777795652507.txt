You are a senior frontend architect and UI/UX designer.

Build a production-grade frontend using Next.js (App Router, TypeScript) for an AI-powered Prescription Discrepancy Detection System.

The system is designed for pharmacists and clinical professionals.

IMPORTANT:

* This is NOT an ML-focused product.
* The system is driven by:

  1. Rule-based safety checks (primary)
  2. AI clinical reasoning (RAG + LLM)
* Any ML components are internal and MUST NOT be highlighted in the UI.

---

🔥 DESIGN PHILOSOPHY

The UI must feel like:

* A clinical decision support system (CDSS)
* A hospital-grade tool
* Trustworthy, minimal, and precise

Avoid:

* “AI flashy startup” look
* Overly colorful dashboards
* Any mention of ML confidence models

---

🎨 VISUAL DESIGN

Theme:

* Clean medical interface (like EHR / pharmacy systems)

Colors:

* Primary: Deep Blue (#0B3C5D)
* Secondary: Teal (#2EC4B6)
* Status Colors:

  * Red → Critical issue (Commission)
  * Amber → Missing info (Omission)

Typography:

* Inter / IBM Plex Sans
* Highly readable, professional spacing

UI Feel:

* Soft shadows
* Rounded-xl cards
* Subtle gradients only
* Calm and confidence-inspiring
